# Historical V1 maintenance patches

These one-time scripts are preserved for historical reference. They are not part of the Disney App 2.0 (DAv2) runtime and are not required by the current repository development tools. Their contents are preserved exactly as they were before archiving.

The scripts may contain unsafe or obsolete assumptions, including V1 folder instructions, legacy cache identifiers, targets relative to the working directory or script location, and backups outside the repository. Their original repository-root location assumptions no longer hold in this archive.

**Do not execute these scripts without a fresh review of all targets, identifiers, and planned writes under the current root AGENTS.md rules. Never run them against the V1 repository or its local folder.**
